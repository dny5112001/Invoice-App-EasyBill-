# Easy Bill

Easy Bill is a React Native application designed for seamless invoice generation. It allows users to create, manage, and export invoices efficiently, making billing processes easier and more organized.

## Features

- Create and manage invoices
- Store business and client details
- Add multiple items with pricing and quantity
- Apply discounts, taxes, and shipping charges
- Calculate total amounts automatically
- Save and retrieve past invoices
- Export invoices as PDF
- User-friendly interface with smooth navigation

## Installation

To run Easy Bill locally, follow these steps:

1. Clone the repository:
   ```sh
   git clone https://github.com/your-repo/easy-bill.git
   ```
2. Navigate to the project folder:
   ```sh
   cd easy-bill
   ```
3. Install dependencies:
   ```sh
   npm install
   ```
   or
   ```sh
   yarn install
   ```
4. Start the application:
   ```sh
   npm start
   ```
   or
   ```sh
   expo start
   ```

## Usage

1. Open the app and set up your business details.
2. Create a new invoice by adding client information and item details.
3. Apply taxes, discounts, and shipping charges if needed.
4. Save the invoice for future reference.
5. Export the invoice as a PDF for easy sharing.

## Technologies Used

- **React Native** - For mobile development
- **Expo** - For quick deployment and testing
- **Zustand** - For state management
- **react-native-pdf** - For PDF generation
- **expo-file-system** - For file management
- **expo-print** - For printing and PDF handling
- **react-native-svg & Charts** - For visual data representation
- **AsyncStorage/SQLite** - For local data storage
- **React Navigation** - For app navigation
- **expo-image-picker** - For handling images
- **expo-mail-composer** - For sending invoices via email
- **react-native-webview** - For embedding web content
